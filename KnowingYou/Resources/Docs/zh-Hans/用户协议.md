# 用户协议

感谢你使用知鱼录音（以下简称"本软件"）。在使用前，请阅读以下条款。

## 1. 软件性质

本软件是一个完全在本地运行的 macOS 应用：不联网、不收集数据、没有账号体系、没有云同步。你对本软件产生的所有录音、纪要、截图等文件拥有完全的控制权，它们只存在于你在偏好设置里指定的本地文件夹中。

## 2. 录音合规责任

**你需要自行确保录音行为符合适用法律法规。** 在许多地区，未经参会者同意录制会议或通话可能涉及法律风险（例如部分地区要求"单方同意"，另一些地区要求"全体同意"）。使用本软件前，请：

- 确认你所在地区及会议对方所在地区对录音的法律要求；
- 在录音前明确告知所有参会者本次会议将被录音，并获得所需的同意；
- 不要将录音内容用于任何法律不允许的用途。

知鱼录音不会、也无法代你核实上述合规情况——弹窗底部的"开始录音即代表你确认所有参会者均已获悉本次会议将被录音"仅是提醒，责任由使用者自行承担。

## 3. 免责声明

本软件按"现状"提供，不附带任何明示或暗示的担保。开发者不对因使用本软件（包括但不限于录音丢失、格式不兼容、检测遗漏等）而产生的任何直接或间接损失承担责任。

## 4. 知识产权

本软件的界面设计参考了 Plaud 桌面客户端的布局，仅用于学习与个人使用目的，去除了其所有联网、账号、云同步与 AI 相关功能。知鱼录音与 Plaud 官方没有任何关联。本软件使用的第三方开源组件见"第三方许可"文档。

## 5. 条款变更

本协议可能随版本更新而修改，最新版本以软件内置文档为准。
