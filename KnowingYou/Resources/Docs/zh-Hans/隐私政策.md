# 隐私政策

## 核心承诺：零联网

知鱼录音**不会以任何方式收集、上传或传输你的任何数据**。具体来说：

- **没有账号系统**：不需要注册、登录，也没有用户识别信息。
- **没有云同步**：所有录音、纪要、截图只保存在你在"偏好设置 → 通用"里指定的本地文件夹，不会上传到任何服务器。
- **没有遥测/统计**：本软件不收集任何使用数据、崩溃报告或分析信息。
- **没有自动更新检查**：关于页的"检查更新"按钮点击后，只是用你系统默认浏览器打开一个网页（GitHub Releases 页面），App 进程本身不会主动发起任何网络连接去检查版本。
- **没有 AI / 云端处理**：所有音频处理（混音、转码）都在你的 Mac 本地完成，不会把任何音频或文字发送到任何第三方服务。

你可以使用 [Little Snitch](https://www.obdev.at/products/littlesnitch/) 或系统自带的网络监控工具，自行验证知鱼录音在运行期间没有发起任何网络连接。

## 本地数据

知鱼录音在本机会读写以下内容，全部保存在你自己的 Mac 上：

- **录音文件**（`.m4a`）与**纪要文件**（`.md`）：保存在你指定的文件夹，默认是"文稿/知鱼录音"。
- **截图**：保存在对应录音同名的子文件夹里。
- **偏好设置**：保存在 macOS 标准的 `UserDefaults`（`~/Library/Preferences/`）中，仅包含你的界面偏好（是否自动录制、快捷键组合等），不包含录音内容。
- **系统日志**：macOS 标准的 `OSLog` 机制会记录本软件的运行日志（用于你主动导出诊断信息时排查问题），日志只存在于本机，知鱼录音不会主动上传日志。

## 系统权限

知鱼录音向系统申请麦克风、系统音频录制、通知、屏幕录制这四项权限，均只用于其对应功能（详见"帮助"文档），不用于任何数据收集目的。你可以随时在"系统设置 → 隐私与安全性"里查看和撤销这些权限。

## 联系方式

如果你对本隐私政策有任何疑问，可以通过"偏好设置 → 通用 → 反馈"发送邮件联系开发者。
