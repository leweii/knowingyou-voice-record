# 帮助

## 怎么用

知鱼录音是一个常驻菜单栏的会议录音工具。日常使用方式：

1. **手动录音**：点菜单栏图标弹出面板，点"开始录音"；再点一次面板里的按钮（此时会变成红色的"停止录音"）结束。
2. **自动录音**（可选）：在"偏好设置 → 录音 → 会议识别"里勾选你常用的会议软件，并打开"偏好设置 → 录音 → 自动录制"。之后只要这些应用开始使用麦克风，知鱼录音会在 3 秒后自动开始录音（如果没打开自动录制，则会弹出通知询问你是否要开始）。
3. **录音中记笔记**：录音开始后桌面右上角会出现一个小浮窗。点浮窗里的笔图标，可以展开成一个可以打字的纪要窗口；停止录音后，纪要会保存成与录音同名的 `.md` 文件。
4. **标记重要时刻**：录音中按下快捷键（默认 ⌥⌘M）或点浮窗里的旗子图标，会在纪要里插入一条时间戳标记，方便回看时快速定位。
5. **截图**：按下快捷键（默认 ⌥⌘S）或点纪要窗里的截图按钮，会截取会议软件当前窗口的画面，存到录音同名的子文件夹里，并在纪要中插入一条引用。

录音结束后，你会在"偏好设置 → 通用 → 数据与存储"里设置的文件夹下找到两个文件：`<时间戳> <应用名>.m4a`（音频）和 `<时间戳> <应用名>.md`（纪要，仅当你写了标题或至少有一条纪要/标记时才会生成）。

## 权限说明

知鱼录音需要以下系统权限，都是首次实际使用对应功能时才会申请（不会一开机就把所有权限弹窗糊你一脸）：

- **麦克风**：录制你自己的声音，第一次点"开始录音"时申请。
- **系统音频录制**（macOS 系统权限名称可能显示为"屏幕与系统音频录制"）：录制会议对方通过扬声器播放出来的声音，同样在第一次录音时申请。
- **通知**：会议提醒、录音已保存等系统通知，首次启动引导时申请。
- **屏幕录制**：仅截图标记功能需要，第一次点截图按钮时才申请。

如果你不小心拒绝了某个权限，可以在"系统设置 → 隐私与安全性"里手动重新开启，或者点知鱼录音对应设置项旁边的"去授权"按钮直接跳转。

## 常见问题

**录不到系统声音（对方说话录不进去）？**
先确认"偏好设置 → 录音 → 系统音频"开关是打开的；再检查"系统设置 → 隐私与安全性 → 屏幕与系统音频录制"里知鱼录音是否已勾选。这两个条件都满足后，重新开始一次录音即可。

**为什么没有弹出会议检测通知？**
确认"偏好设置 → 通知 → 会议开始提醒"是打开的，以及"偏好设置 → 录音 → 会议识别"里对应的会议软件已经勾选。另外，如果"自动录制"是打开的，检测到会议后会直接开始录音而不会弹通知——这是设计如此，不是 bug。

**录音文件在哪？**
"偏好设置 → 通用 → 数据与存储 → 录音保存路径"显示了当前的保存位置，点旁边的"在 Finder 中显示"可以直接打开。默认在"文稿/知鱼录音"（或英文系统下的 "Documents/Knowing You"）。

**浏览器里开的会议（比如网页版腾讯会议）能自动录音吗？**
不会自动开始，只会弹通知询问。因为知鱼录音只能判断"浏览器正在使用麦克风"，无法判断具体是哪个网站，为了避免误录，浏览器场景一律需要你手动确认。

**换了新麦克风 / 断开耳机，正在录的音频会中断吗？**
"麦克风"选项选"智能选择"时，知鱼录音会跟随系统默认输入设备自动切换，不会中断录音；纪要里也会自动插入一条"麦克风切换到 XXX"的记录。
