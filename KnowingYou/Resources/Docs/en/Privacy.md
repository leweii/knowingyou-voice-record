# Privacy Policy

This document is a placeholder; full content lands in S19.

**Core promise: zero network.** Knowing You collects and uploads nothing; no accounts, no cloud sync, no telemetry, no auto-update checks (the About page's "Check for Updates" button only opens a web page in your system browser — the app process itself never makes a network request). All recordings and notes are saved only to the local folder you choose in General settings. You can verify this yourself with a tool like Little Snitch.
