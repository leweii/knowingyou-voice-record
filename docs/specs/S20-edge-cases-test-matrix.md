# S20 边界情况 + 手工测试矩阵

## 目标
把计划 §9 M4 与 §11 列的边界情况逐一处理，并把手工测试矩阵写成文档、执行一遍、记录结果。发布前的质量门。

## 范围
### 做
- 逐条处理并写明行为（每条对应代码位置写在 PR 里）：
  | # | 场景 | 期望行为 |
  |---|---|---|
  | 1 | 录音中拔麦克风 / 蓝牙断开 | 切到默认设备继续，纪要加事件；无可用输入则只录系统音频并通知 |
  | 2 | 录音中休眠 → 唤醒 | 唤醒后继续录（时间轴补零）或自动停止并保存（选一种，写决策）；不能丢已录部分 |
  | 3 | 磁盘满 | 停止并保存已录部分（CAF 转码若失败保留 CAF），通知"磁盘空间不足" |
  | 4 | 保存目录被删除 / 外置盘拔出 | 开录前拦截 alert；录制中切到 `~/Documents/知鱼录音` 备用目录并通知 |
  | 5 | 同秒两次开录 | ` (2)` 后缀（S10 已覆盖，验一次） |
  | 6 | app 被 kill -9 / 崩溃 | 下次启动恢复 CAF（S10），`.md` 已落盘部分保留 |
  | 7 | 录音中切换输出设备 | 系统音频继续（S08），允许 <300 ms 空洞 |
  | 8 | 3 小时长录音 | 内存平稳（<150 MB），转码 <60 s，文件可播 |
  | 9 | 两个会议软件同时用麦 | 触发应用取最早者；文件名一个 |
  | 10 | 会议软件崩溃 | 10 s 后自动停止（与正常退会一致） |
  | 11 | 系统音频权限中途被撤销 | tap 失败 → 只录麦克风并通知，不崩 |
  | 12 | 用户在 Finder 改名 / 删除正在录的文件 | 录制不受影响（fd 已打开）；停止时若目标不存在则重建 |
  | 13 | 语言切换后目录名 | 不变（S03 决策）验一次 |
  | 14 | 通知权限被拒 | 询问流程退化：菜单栏图标变色 + 弹窗内提示"检测到 X，开始录音？" |
- `docs/testing/manual-matrix.md`：矩阵 = 会议软件（腾讯会议 / 飞书 / 钉钉 / Zoom / Teams / Chrome Meet）× 麦克风（内置 / USB / 蓝牙）× 系统版本（14.4 / 15 / 26，按可获得的机器）；每格记录：检测延迟、自动停止延迟、双源有声、文件名正确。另有上表 14 条场景的执行记录。
- 修复矩阵暴露的 P0（丢录音 / 崩溃 / 权限死循环）与 P1（检测失败 / 文件名错）。
