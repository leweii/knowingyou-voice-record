# S22 UI 重设计

## 目标
2026-09-30 Jakob 对 Plaud 克隆版 UI 不满意，要求**在不改动功能的前提下**换一套有统一设计语言的新 UI，并把动效做成 app 的一大特色。方向经 HTML 原型评审后拍板：**深色专业**（青 `#3DDBD9` 为唯一操作强调色、红 `#FF4D5E` 只表示"正在录音"），浅色 / 深色两套主题都支持，允许调整布局。原型见 [`docs/design/ui-prototype.html`](../design/ui-prototype.html)，是本 spec 的视觉依据，取代 `02-ui-spec.md` 里"像素级还原 Plaud"的要求（该文档仅保留为功能元素清单）。

## 范围
### 做
- `DesignSystem/` 重写：动态（深 / 浅）颜色 token、字体层级、圆角阶梯、动效 token（`KYMotion`）；所有控件换新样式。
- 全部界面迁移到新 token：偏好设置 5 页 + 侧栏、菜单栏弹窗、会议检测 / 录音已保存浮动卡片、录音浮窗（胶囊 + 笔记窗）、首次引导、文档阅读窗、DEBUG 控件库。
- 招牌动效（原型 §06）：M1 鱼游入 Logo、M2 录音键变形、M3 胶囊 ⇄ 笔记窗弹性变形、M4 会议检测声纳、M5 保存（波形→文件→文件夹）、M6 标记冲击波 / 截屏快门、M7 暂停排空，以及呼吸点、录音中流光边框、侧栏弹性指示器、页面切换渐入。
- 所有循环 / 叙事动效遵守系统"减弱动态效果"。

### 不做
- 任何功能、状态机、文件格式、偏好项的变化。
- 原型 M8"主题切换圆形揭示"：原生 app 跟随系统外观，没有 app 内主题开关（加开关属于新功能）。

| 2026-09-30 | 电平表保留滚动历史（每根柱子是不同时刻的读数），只换配色（按高度青→黄→红） | 2026-09-24 Jakob 否定过"所有柱子一起跳"的 VU 样式 |
| 2026-09-30 | 胶囊保留停止按钮 | 原竖条有停止键，去掉即功能缺失 |
| 2026-09-30 | 胶囊改为横向 264×48（原型为 300×56，收紧一些） | 原竖条 44×175 是 Jakob 嫌大后才缩的，横向胶囊面积仍控制在接近的量级 |
| 2026-09-30 | 浮窗默认位置从屏幕右侧中部改为右上角菜单栏下方 | 横向胶囊放右上更像"灵动岛"，也更少挡会议画面；已保存过位置的用户不受影响 |
| 2026-09-30 | `KYPopup` 用自绘按钮 + 原生 `NSMenu`，不用 SwiftUI `Menu` | `Menu` 的 `.borderlessButton` 样式会丢弃自定义 label 的背景 / 描边（快照 QA 发现），无法做出带边框的字段样式 |
| 2026-09-30 | 设置页各行分隔线由行自身在顶部绘制，首行的线与卡片描边重合 | `Group(subviews:)` 需 macOS 15，部署目标是 14.4 |
| 2026-09-30 | M5 保存动画改为原地完成（波形→文件→文件夹同一位置） | 最初的"飞入右侧文件夹"版本静止后左侧留下大块空白，卡片显得失衡 |
| 2026-09-30 | Dock / App 图标与菜单栏图标也换成鱼形声波标志（推翻 README §2 #11 的占位决定） | Jakob 明确要求"docker 的 icon 和 top bar 的 icon 都改成你设计的样式"；App 图标由 `scripts/make-app-icon.swift` 按 `KYMarkGeometry` 生成，菜单栏为运行时绘制的模板图；发布门禁改为校验图标资源存在、防回退到占位 |
| 2026-09-30 | 视觉 QA 用应用内 `cacheDisplay` 自渲染快照 | 本机 agent 宿主没有屏幕录制权限，`screencapture` 全部失败；该方法不渲染毛玻璃与 `ScrollView` 内容，QA 时临时替换为 `VStack` |
| 2026-10-08 | `WaveformView` 改为在 `TimelineView(.animation)` 里按显示器刷新率重绘，按固定 50 ms 从时间轴采样新柱（`WaveformHistory`），柱子在两次采样之间按比例平滑左移，最右边多一根"实时柱"从右侧滑入；取代"每次 level 变化整排瞬间左移一格" | Jakob 反馈"波形图的帧数太低了，看起来在一直刷新"。原实现每秒约 20 次整格跳动，看起来像在闪/刷新；现在滚动是连续的。临时调试钩子实测：电平只以 20 Hz 送达时，每个波形仍以约 100 次/秒重绘（钩子已移除）。按时间轴而不是按 level 事件采样，也让柱子在电平事件不均匀到达时保持等距。暂停时 `TimelineView` 暂停，恢复时 `restartClock()` 不回填暂停期间的柱子；"减少动态效果"下不做小数位移 |
