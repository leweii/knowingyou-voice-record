招牌动效

让“知鱼”这个名字真的动起来。每个动效都循环播放，悬停可重播；右上角切换主题会触发圆形揭示。

M1
鱼游入 · 启动 / 关于页声波条依次弹起、跳动，最后鱼尾摆动两下。Logo 本身就是一段录音。1.2s · spring · 仅首启 + 关于页
M2
录音键变形按下回弹 → 青变红，圆点弹性收成圆角方块（停止符号），同时向外发三圈脉冲。0.45s · spring(0.4, 0.7)

暂停 · 声音排空波形塌缩成一条灰线，状态点从呼吸的红变成静止的琥珀色；继续时再“充”回来。0.4s · ease-out
常驻的小动效

录音中：状态点呼吸 1.6s、弹窗边框流光 3s、电平表 20fps。
待命：波形微弱“呼吸”，表示在听但没在录。
悬停：卡片跟随鼠标的青色聚光、关于页特性卡 3D 倾斜。
全部遵守系统“减弱动态效果”设置。

从点击位置扩散（View Transitions）
M8
环境动效 + 主题揭示在 SwiftUI 中对应 .phaseAnimator / .keyframeAnimator / matchedGeometryEffect，全部 macOS 14 可用。
动效等级曲线时长用在哪SwiftUI 对应
微交互150–200ms按钮按下、悬停、开关.easeOut(0.18)
状态切换350–450ms录音键变形、侧栏指示器、分段控件.spring(response: 0.4, dampingFraction: 0.7)
窗口变形550ms灵动岛 ⇄ 笔记窗、弹窗出现.spring(response: 0.55, dampingFraction: 0.75)
叙事动效0.9–1.4s启动、会议检测、保存完成.keyframeAnimator
环境循环1.6–3s ∞呼吸点、流光边框、待命波形.phaseAnimator / TimelineView

P1两种强调色

青 = 可操作 / 声音在流动；红 = 正在录音。其它一律中性灰阶。

P2卡片即分组

设置项按卡片分组，行内左图标 + 右控件，取代细分割线。

P3动效有意义

弹性只用于状态切换（开关、指示器、浮窗变形），呼吸 / 流光只在录音中出现。

P4圆角阶梯
